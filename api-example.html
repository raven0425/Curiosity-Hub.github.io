Random Text API (Quotable)

API Documentation

Endpoint: https://api.quotable.io/random

Returns a JSON object:

{
  "content": "Quote text here",
  "author": "Author name"
}

Explanation:

// fetch() calls the API
// .then(res => res.json()) converts JSON string to object
// data.content and data.author are extracted
// DOM is updated with text

GitHub Emoji API

API Documentation

Endpoint: https://api.github.com/emojis

Returns a JSON object mapping names → image URLs:

{
  "smile": "https://github.githubassets.com/images/icons/emoji/unicode/1f604.png",
  "heart": "https://github.githubassets.com/images/icons/emoji/unicode/2764.png",
  ...
}

Explanation:

// fetch() calls the API
// Object.keys(data) gets all emoji names
// A random name is selected
// The image URL is inserted into the DOM

Yes / No API

API Documentation

  "image": "URL to GIF"
}

Explanation:

// fetch() calls the API
